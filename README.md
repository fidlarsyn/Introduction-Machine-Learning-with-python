# Introduction Machine Learning with python

**Bab 1: Introduction**

Bab ini memperkenalkan konsep dasar machine learning dan aplikasinya dalam dunia nyata. Fokus utamanya adalah membangun aplikasi pertama menggunakan algoritme k-Nearest Neighbors (k-NN) untuk mengklasifikasikan spesies bunga Iris. Kamu akan mempelajari alur kerja dasar: memuat data, membagi data train/test, membangun model, dan mengevaluasi akurasi.

**Bab 2: Supervised Learning**

Membahas berbagai algoritme Supervised Learning yang paling sering digunakan dalam praktik, baik untuk tugas klasifikasi maupun regresi. Algoritme yang dipelajari meliputi model linear, decision trees, ensembles (seperti Random Forests dan Gradient Boosting), Support Vector Machines (SVM), hingga Neural Networks. Bab ini juga menjelaskan konsep penting seperti overfitting, underfitting, dan generalisasi.

**Bab 3: Unsupervised Learning and Preprocessing**

Bab ini mengeksplorasi teknik untuk menemukan pola dalam data tanpa label. Fokus utamanya mencakup prapemrosesan data (seperti scaling), reduksi dimensi menggunakan Principal Component Analysis (PCA) dan Non-Negative Matrix Factorization (NMF) untuk visualisasi atau ekstraksi fitur, serta berbagai metode Clustering seperti k-Means, Agglomerative Clustering, dan DBSCAN.

**Bab 4: Representing Data and Engineering Features**

Menekankan pentingnya cara merepresentasikan data agar dapat diproses secara optimal oleh algoritme. Topik yang dibahas meliputi penanganan variabel kategorikal melalui one-hot-encoding, teknik binning, pembuatan fitur polinomial dan interaksi, serta metode seleksi fitur otomatis untuk meningkatkan performa model.

**Bab 5: Model Evaluation and Improvement**

Berfokus pada metode evaluasi yang lebih kuat di luar pembagian data tunggal. Anda akan mempelajari teknik Cross-Validation untuk penilaian performa yang stabil, Grid Search untuk pencarian parameter terbaik, serta penggunaan berbagai metrik evaluasi seperti Confusion Matrix, Precision-Recall, dan kurva ROC/AUC untuk menangani dataset yang tidak seimbang.

**Bab 6: Algorithm Chains and Pipelines**

Memperkenalkan kelas Pipeline untuk menyederhanakan proses penyambungan berbagai langkah pemrosesan data dan model ke dalam satu objek tunggal. Penggunaan pipeline sangat krusial saat melakukan Grid Search untuk menghindari kebocoran data (data leakage) selama proses validasi silang.

**Bab 7: Working with Text Data**

Bab ini membahas cara mengolah data teks menjadi representasi numerik yang dapat dipahami oleh mesin. Teknik yang dipelajari meliputi model Bag-of-Words, pembobotan tf-idf, penggunaan n-grams untuk menangkap konteks, pemrosesan bahasa alami (NLP) tingkat lanjut seperti lemmatization, hingga pemodelan topik menggunakan Latent Dirichlet Allocation (LDA).

**Bab 8: Wrapping Up**
Memberikan panduan strategis dalam mendekati masalah machine learning secara keseluruhan, mulai dari pembuatan prototipe hingga sistem produksi. Bab ini juga memberikan instruksi praktis tentang cara membangun Estimator Kustom kamu sendiri agar kompatibel dengan antarmuka scikit-learn
